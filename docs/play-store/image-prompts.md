# Tickd Play Store image prompts

Attach a real screenshot with each screenshot prompt. Use demo tasks and amounts; remove personal information before uploading. Generate each image separately with the same visual style. Export screenshots at 1080 × 1920 px and the feature graphic at 1024 × 500 px, in JPEG or opaque PNG. If the generator returns a different size, resize the final export to the required dimensions without stretching the UI.

## Screenshot master prompt

```text
Create one polished Google Play promotional screenshot for Tickd using my attached app screenshot as the source of truth. Output a portrait 1080 x 1920 composition.

Style: premium, calm, modern productivity. Warm ivory background, soft lavender and peach gradients, restrained mint accents, subtle paper texture and small botanical shapes. Clean editorial typography, generous spacing, soft realistic shadows. Keep the same palette and typography across the full screenshot series.

Place the supplied screenshot straight-on as the main visual, occupying about 75% of the canvas height. Use a thin rounded border and a soft shadow. Preserve its aspect ratio and keep all important UI visible. Preserve every UI label, task, icon, button, colour and layout exactly. Do not redraw, translate, invent or replace any part of the app interface. Decorative shapes belong outside the screenshot. If exact preservation is impossible, generate only the background and headline with a blank area for manual placement of the original screenshot.

At the top, add exactly this headline: "[HEADLINE]"
Below it, add exactly this subtitle: "[SUBTITLE]"
Keep the headline and subtitle together below 20% of the total image area, with high contrast and comfortable margins. Make the app interface the hero.

No ratings, testimonials, awards, ranking claims, prices, download counts, Play Store badges, fake notifications, extra UI panels, hands or people. No watermark. No claims about features absent from the attached screenshot.
```

Replace the two placeholders with one row below. Use the matching actual screen.

| Order | Capture | Headline | Subtitle |
| --- | --- | --- | --- |
| 1 | Home with today's demo tasks | Your day, beautifully planned | Keep today's tasks in one place. |
| 2 | Task editor showing repeat options | Make routines feel effortless | Repeat daily, weekly or monthly. |
| 3 | Task with reminder time selected | Remember what matters | Set reminders for your daily plans. |
| 4 | Wallpaper gallery or Home with wallpaper | A little joy in every plan | Choose a look that feels like you. |
| 5 | Smart Dashboard with real focus list | See what needs your focus | View priorities and overdue tasks. |
| 6 | Smart Finance with demo entries | Keep everyday spending in view | Record income and expenses simply. |

Use the first four for the initial set. Include an AI-specific screenshot only after the release build produces a genuine successful AI response. Never fabricate a response for the listing.

## Feature graphic prompt

```text
Design a premium Google Play feature graphic for Tickd, a task and routine planner. Landscape composition, final export exactly 1024 x 500 pixels, opaque background.

Create a warm ivory-to-lavender gradient with soft peach and mint accents. Use elegant abstract task cards, small checkmarks, calendar shapes and subtle botanical details to suggest an organised, calm day. These are decorative illustrations, not invented screenshots of the app. Use depth sparingly, with refined shadows and generous breathing room.

Place the text "Tickd" and the tagline "Plan your day. Build your routine." clearly within the central area. Keep all essential text and focal elements away from the edges for cropping. Balance typography on the left with a flowing illustration on the right; keep the centre cohesive. Do not duplicate a large app icon. No phone frame, ratings, awards, ranking claims, pricing, badges, testimonials or watermark. Premium and welcoming, with crisp legible typography.
```

## Export check

Check every generated word against the original screenshot. If UI text has changed, composite the original screenshot over the generated background before uploading. Use the same demo data, language and palette across the series. Keep source screenshots as separate originals.

Google's [preview asset guidance](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en-GB) specifies 1024 × 500 for the feature graphic and recommends four 1080 × 1920 portrait screenshots for eligible recommendation placements; graphics must accurately represent the app.
